Colocá aquí tus imágenes para el panel izquierdo del launcher.

Formatos admitidos:
- PNG
- JPG / JPEG
- WEBP

Resolución recomendada:
- 800 x 1200 px
- orientación vertical
- relación 2:3

El script elegirá una imagen aleatoria cada vez que abras Rofi.

IMPORTANTE PARA GITHUB:
Usá solamente imágenes que tengas derecho a redistribuir.
El repositorio puede mantenerse sin imágenes y cada usuario puede agregar las suyas.
